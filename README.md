## 📥 Что это

Локальный HTML-файл, который подтягивает список прокси и новости с GitHub и показывает их в удобном виде. Работает **без установки**, открывается в любом браузере.

**Требования:** интернет (файл тянет данные с `raw.githubusercontent.com`).

---

## 🚀 Быстрый старт

### 1. Скачай файл
Из раздела **Releases** скачай:
- `index.html` — если в релизе один файл
- `index.zip` — если архив, распакуй его

### 2. Запусти одним из способов ниже 👇

---

## 💻 Windows

**Способ 1 — двойной клик (самый простой):**
- Найди `index.html` → двойной клик → откроется в браузере по умолчанию

**Способ 2 — через браузер:**
- `Ctrl + O` в Chrome / Edge / Firefox → выбери файл

**Способ 3 — ПКМ:**
- Правый клик по файлу → «Открыть с помощью» → браузер

---

## 🍎 macOS

**Способ 1 — Finder:**
- Двойной клик по `index.html`

**Способ 2 — Терминал:**
```bash
cd ~/Downloads
open index.html
```

**Способ 3 — локальный сервер (если браузер блокирует fetch):**
```bash
cd ~/Downloads
python3 -m http.server 8000
```
Затем открой в браузере: **http://localhost:8000**

---

## 📱 Android

**Способ 1 — файловый менеджер:**
- Открой «Файлы» / «Мои файлы» → найди `index.html` → тапни

**Способ 2 — Chrome вручную:**
```
file:///sdcard/Download/index.html
```

**Способ 3 — Termux (если нужен локальный сервер):**
```bash
pkg install python
cd /sdcard/Download
python -m http.server 8080
```
Открой: **http://localhost:8080**

**Способ 4 — приложение:**
- Установи **HTML Viewer** или **DroidEdit** из Play Store

---

## 📱 iPhone / iPad

**Способ 1 — приложение «Файлы»:**
- Сохрани `index.html` в «Файлы» → тапни по нему (базовый предпросмотр)

**Способ 2 — a-Shell (рекомендуется, полный функционал):**
1. Установи **a-Shell** из App Store
2. Открой и выполни:
```bash
cd ~/Documents
python3 -m http.server 8080
```
3. В Safari открой: **http://localhost:8080**

**Способ 3 — Koder:**
- Установи **Koder** → открой файл → предпросмотр

## ⚠️ Важно

| Проблема | Причина / Решение |
|----------|-------------------|
| Пустой список, ошибка `CORS` | Открываешь через `file://` — запусти через локальный сервер (`python -m http.server`) |
| Ошибка `HTTP 404` | Файлы `proxies.txt` / `news.json` недоступны в репозитории |
| Нет интернета | Файл тянет данные с `raw.githubusercontent.com`, нужен онлайн |
| Кнопка «Открыть» не работает | Ссылки `tg://` открываются только в Telegram |
| Кракозябры в новостях | Проверь кодировку — файл должен быть UTF-8 |

---

## 🔧 Как это работает

- Загружает `proxies.txt` и `news.json` с GitHub
- Парсит строки: ссылки `tg://proxy?...`, `https://t.me/...` и простой формат `server port secret #comment`
- Строит кнопки «Открыть» → запускают Telegram с готовым прокси
- Кнопка 🔄 **Обновить** перезагружает список
